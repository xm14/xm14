# Software Engineer

I build and improve web systems with Ruby on Rails. My work is directed at
business outcomes: faster delivery, reduced manual effort, and integration of
AI capabilities into applications that are already in operation.

## What I do for businesses

**Accelerate development cycles.**
Rails projects often accumulate friction: unclear domain boundaries, slow test
suites, manual deployment steps. I identify where time is lost and remove it.
The result is shorter cycles from idea to production.

**Automate manual workflows.**
Recurring operational tasks — data processing, reporting, synchronization
between services — consume hours that should be spent on growth. I design and
implement automation that runs reliably and requires minimal oversight.

**Integrate AI into existing applications.**
AI is not a separate product. It is a capability that belongs inside the tools
a business already uses. I build service layers that connect external AI
services to Rails applications without compromising architecture, testing, or
data integrity.

## How I work

I read the business problem before I write code. I prefer explicit decisions
over assumptions. I document what was built and why. I test behavior, not
methods. A system is only as good as its ability to keep working when
conditions change.
